# MARV Target Description Files (`.mvt`)

A `.mvt` target description file is a `(marv-target ...)` S-expression specifying the target backend type (`wcpl`, `cc`, or `rv64g`), object file extension, and the command parameters used to invoke the target compiler and linker.

`marv` requires a `-t TARGDES` option on every invocation and resolves `TARGDES` by searching the target lookup directories (`-T DIR`, defaulting to `("./")`) for `<DIR>/<TARGDES>.mvt`.

---

## Included Target Files

All sample `.mvt` files assume that the corresponding compiler/linker is installed and available in your `PATH`:

| File | `-t` Name | Target Type | Object Ext | Compiler / Linker Assumed in `PATH` |
|---|---|---|---|---|
| `wcpl.mvt` | `wcpl` | `wcpl` | `.wo` | `wcpl` (WCPL WebAssembly compiler/linker) |
| `cc.mvt` | `cc` | `cc` | `.c` | `cc` (system C99 compiler) |
| `gcc.mvt` | `gcc` | `cc` | `.c` | `gcc` |
| `clang.mvt` | `clang` | `cc` | `.c` | `clang` |
| `cl.mvt` | `cl` | `cc` | `.c` | `cl` (Windows MSVC compiler) |
| `rv64g.mvt` | `rv64g` | `rv64g` | `.s` | `cc` (native RISC-V 64-bit LP64D C compiler) |
| `rv64g-cross.mvt` | `rv64g-cross` | `rv64g` | `.s` | `riscv64-linux-gnu-gcc` (RISC-V 64-bit cross-compiler) |

Every `.c` object file generated by `marv` for the `cc` target embeds the MARV C99 runtime definitions directly at the top of the generated `.c` file, and every `lib/*.c` adapter file is self-contained, so no extra `-I` include flags are required in `.mvt` files.

---

## `.mvt` Entries

| Key | Value Type | Description |
|---|---|---|
| `name` | String | Target designation name. |
| `type` | Symbol (`wcpl`, `cc`, or `rv64g`) | **Required.** Selects the MARV code generator backend. |
| `obj-ext` | String (`".wo"`, `".c"`, or `".s"`) | Optional override for the object file extension (defaults to `.wo` for `wcpl`, `.c` for `cc`, and `.s` for `rv64g`). |
| `link-cmd` | String template | Command template used in link mode (without `-c`). Supports `~exe` (replaced by the `-o` executable path) and `~src` (replaced by space-separated object files and automatically discovered `lib/*.c` system adapters). |
| `cc` | String | Compiler binary name (used if `link-cmd` is omitted). |
| `cflags` | List of strings | Compiler flags (used if `link-cmd` is omitted). |
| `ldflags` | List of strings | Linker flags (used if `link-cmd` is omitted). |
| `ldlibs` | List of strings | Linker library flags such as `("-lm")` (used if `link-cmd` is omitted). |

---

## Example Custom `.mvt` File

If your WCPL installation keeps its standard library in a custom directory (for example `/opt/wcpl/lib`), you can create a custom `my-wcpl.mvt` file:

```scheme
(marv-target
  (name     "my-wcpl")
  (type     wcpl)
  (obj-ext  ".wo")
  (link-cmd "wcpl -I/opt/wcpl/lib/include/ -L/opt/wcpl/lib/ -o ~exe ~src"))
```

And invoke `marv` with `-t my-wcpl`:

```sh
marv -T targets -t my-wcpl -o prog.wasm prog.mvs
```
